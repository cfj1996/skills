# 多页面前端验收方案对比

对服务商报表这类多页共享筛选的需求，建议开发先跑通一条跨页路径。首个具有代表性的页面做一次原型对照，最终验收复核 Zan 用法及全部受影响用例。是否启用专门的 UI 评审角色，可以在开工时按页面差异决定。

## 两种做法

| | A · UI 对齐、主开发、功能与 Zan 验收 | B · 按跨页业务路径开发与验收 |
| --- | --- | --- |
| 开工前 | UI 评审者按角色、页面和状态标出原型要求。主开发明确复用的组件和已有实现。 | 从已有 UI 中挑出风险最高的一条路径，把前提、原型与规范依据、操作及可观察结果写入已有 TC。 |
| 开发中 | 主开发写代码。首个代表页面可交 UI 角色在同一视口对照，及时纠正后续页面会复用的布局。 | 主开发先实现这一条路径。连续观察页面、请求和状态，确认下钻、导出、返回等交接都正确，再复用这套做法。 |
| 验收 | UI 角色核对页面。功能与 Zan 评审者核对实际源码、请求次数与字段、异常或中间状态。主开发汇总重叠发现。 | 沿用现有独立评审，按路径复核，并逐条核对同范围普通用例。局部开工会列出路径涉及的其他功能，实施范围由原启动选择决定。 |
| 适用情形 | 多种页面布局、原型对齐难，或项目引入了不熟悉的 Zan 配方。需要给各角色明确的对照物和交付物。 | 下钻、筛选回填、跨页权限、导出等联动容易出错。分支状态仍需独立用例，视觉判断仍需原型和实际页面。 |

## 用同一份服务商样例复核

固定修订 `fixture-r7`、角色、1440×900 视口、源码片段、渲染及请求记录。两组拿到语义相同的五步预期、两个模块和下载状态用例。A 用普通文字，分别交给两名只读评审者。B 用正式计划工具生成有序步骤，交给一名只读评审者。比较的是验收阶段，使用合成数据。[共同输入](review-report-flow.md) · [计划及用例](../../assets/example-report-flow.md)

| 观察项 | 两组首轮均指出的结果 |
| --- | --- |
| 概览布局 | 原型要求八张卡四列两行，同一视口下实测为三、三、二。 |
| Zan 表格查询 | 下钻后的服务商和页码正确。Table 按条件读取，页面又监听同一条件手动刷新，一次点击产生两次相同请求。 |
| 导出条件 | 导出误用了尚未提交的草稿，并丢失已选服务商 ID。 |
| 返回重置 | 输入框清空后，请求仍带原服务商 ID，列表只显示该服务商的门店。 |

A 的两名评审者有重复发现，也都指出「生成中」任务缺少样本。B 首轮只在主路径上验证了已完成任务。两组均指出本地样本返回 200 只覆盖该文件入口，从本次导出到目标环境文件仍需联验。

据此调整了 B 的开工输出，将同范围普通用例与相关跨页路径同时列出。单独选择下载中心也能看到经过该页的报表路径。用更新后的输出复验，同一名 B 评审者标出了「生成中」待补证。一次合成演练能比较漏检位置，实际项目的耗时、首次交付质量和返工轮数仍待实测。[B 的执行方式](../../references/cross-page-acceptance.md)

## 文档收录到什么程度

接口在项目级清单登记一次，功能点引用编号。只把会改变开发或验收判断的决定写入用例，例如「导出取已提交的筛选」「重置后的请求省略服务商 ID」。项目级 Zan 配方引用实际版本和入口，各页面记录自己的差异。验收时留下同状态的原型与页面对照、实际调用或断言、尚缺的证据。后续变更同步到原功能及用例。

## 可参考的公开实践

- Codex 官方有浏览器复现、源码定位和单一实现者协作的自定义子智能体示例，适合参考 A 的角色权限与交接。[Codex Subagents](https://developers.openai.com/codex/subagents)
- Playwright 的测试代理用 Markdown 场景交接预期和测试，视觉对比支持固定环境下的截图差异。项目可以先人工确认与原型一致的基准，再用于回归。[Test Agents](https://playwright.dev/docs/test-agents) · [Visual comparisons](https://playwright.dev/docs/test-snapshots)
- Anthropic 的长任务示例把用户可观察的行为拆成步骤，逐项实现并用浏览器验证，适合参考 B 的开发节奏。[工程实践](https://www.anthropic.com/research/effective-harnesses-for-long-running-agents) · [示例代码](https://github.com/anthropics/claude-quickstarts/tree/main/autonomous-coding)
