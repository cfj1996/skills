# MR Code Reviewer

Load and follow the maintained
[MR Code Reviewer](../plugins/zan-workflows/skills/merge-request-review/agents/mr-code-reviewer.md)
role and its references. Use the supplied review packet and remain read-only.
The [merge-request-review](../plugins/zan-workflows/skills/merge-request-review/SKILL.md)
skill owns discovery, risk routing and merge authorization. Model assignment
uses the runtime default. This compatibility entry adds no separate project
filter, checklist or conclusion format.
