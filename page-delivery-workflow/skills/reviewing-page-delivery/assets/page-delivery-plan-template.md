# 页面交付 Plan

> 一个页面或一个内聚功能模块对应一个 Plan。仅在适用项目 `AGENTS.md` 已确认产物位置规则且用户确认更新 Plan 后创建或更新此文件。

## 交付单元

- 交付单元类型：页面/模块
- `deliveryUnit.kind`：`page` 或 `module`
- 交付单元键：`<稳定键>`
- 交付单元名称：`<项目确认的名称>`
- 产物位置规则来源：`<适用 AGENTS.md 或其委托规范>`
- Plan 内容指纹：`<写入前读取的指纹>`
- 产物位置规则指纹：`<适用规则的指纹>`

模块须有可独立实施、对接和验收的边界；弱关联页面或跨业务域内容应拆分为多个 Plan。

- `PAGE-001`：<职责与边界>；关联：`<F-001, E-001>`

## 路由与参数

- `ROUTE-001`：<路由与参数事实>；关联：`<PAGE-001, DEP-001, E-001>`

## 功能点与业务规则

- `F-001`：<功能与规则>；状态：`待实施`；关联：`<UI-001, API-001, T-001, AC-001>`

## 组件与功能实现方案

- `DESIGN-001`：<项目规范下的组件、职责和状态所有权>；关联：`<F-001, UI-001, API-001>`

## UI 与交互状态

- `UI-001`：<初始、加载、空态、错误、禁用或成功状态>；关联：`<F-001, AC-001>`

## API 与 Mock

- `API-001`：<业务目的、契约来源和已确认事实>；状态：`不涉及接口`；关联：`<F-001, T-001>`
- `MOCK-001`：<Mock 场景或不适用原因>；关联：`<API-001, UI-001>`

## 权限与安全

- `DEP-001`：<来源、目标和依赖状态>；状态：`不涉及`；关联：`<ROUTE-001, F-001, T-001>`

## 实施任务

- `T-001`：<可执行任务>；状态：`待实施`；关联：`<F-001, API-001, DEP-001, AC-001>`

- `AC-001`：<可验证步骤与期望证据>；状态：`未验证`；关联：`<F-001, UI-001, T-001, E-001>`
- `E-001`：<文件、章节、行号、operation 或原型定位>；关联：`<PAGE-001, AC-001>`

## 评审批次

## 客观统计

- 评审结论计数：`<客观数量>`

不得使用页面完成率；不得把不同性质状态折算为单一百分比。

## 遗留问题

- `ISSUE-001`：<阻塞、待确认或冲突>；关联：`<稳定编号>`

## 回写前冲突检查

重新读取 Plan 并比较 Plan 内容指纹及产物位置规则指纹。指纹、稳定编号、状态或双向关联任一冲突时停止写入、展示冲突并等待用户确认；不得部分回写。

不得使用隐藏 JSON、自动生成 Draft、从 Markdown 解析、插件默认 Plan 目录或插件默认 Draft 目录。
