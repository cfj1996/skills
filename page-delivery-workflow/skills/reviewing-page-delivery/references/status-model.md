# 页面交付状态模型

固定状态用于可核验证据，不可据此推断实现已完成。

## 交付单元状态

`评审中 → 可实施 → 开发中 → 待对接 → 待验收 → 已交付`；特殊状态为 `阻塞`。reviewing 只能保持 `评审中` 或设置 `阻塞`；后续 planning 补齐门禁后才可设为 `可实施`。

## 功能状态

`待实施 / 开发中 / 已完成 / 已验证 / 不适用`。

## 接口状态

`不涉及接口 / Draft已确认 / Mock已接入 / 已同步正式契约 / 联调中 / 已验收 / 不适用`。

## 页面依赖状态

`不涉及 / 路由契约待确认 / 待目标页面实现 / 占位页可达 / 页面对接中 / 已对接 / 已验收`。

## 验收状态

`未验证 / 部分通过 / 已通过 / 验收阻塞`。

## 证据门禁与统计

未运行验证不得写“已验证”；Mock 或本地 Draft 验证不得写成真实联调；正式契约未同步到项目契约代码、类型和 Plan 时不得写“已同步正式契约”；未在真实后端环境完成关键状态验收不得写“已验收”。

允许报告本轮评审总数及各结论数量、待复评数量、功能/接口/页面依赖/验收状态数量、任务总数/完成数/验证数和 Draft operation 数量。禁止使用单一页面完成百分比，也不得将不同性质状态折算为页面完成率。
